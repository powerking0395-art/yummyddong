🚗 자동차 연비 예측 계산기

자동차 무게를 입력하면 기존 자동차 데이터를 학습한 모델이 예상 연비를 계산합니다.

예측 방법

  • 선형회귀: 데이터의 경향을 직선으로 표현하여 예측합니다.
  • 비선형회귀: 데이터의 경향을 곡선으로 표현하여 예측합니다.

사용 방법

  1. 자동차 무게를 파운드 단위로 입력합니다.
  2. 예측 모델을 선택합니다.
  3. 연비 예측하기 버튼을 누릅니다.
  4. 예상 연비와 그래프를 확인합니다.

📊 모델 성능 비교

MSE: 예측 오차를 나타냅니다. 값이 낮을수록 오차가 작습니다.
R²: 데이터의 변화 경향을 설명하는 정도입니다. 1에 가까울수록 설명력이 높습니다.
