```html 자동차 연비 예측 계산기
🚗

자동차 연비 예측 계산기

자동차의 무게를 입력하면 머신러닝 회귀 모델을 이용하여 예상 연비를 계산합니다.

📌 계산기 사용 안내

자동차 데이터를 기반으로 선형회귀와 비선형회귀 모델을 학습하여 연비를 예측합니다.

📈 예측 방법

  • 선형회귀 - 데이터의 경향을 직선으로 표현
  • 비선형회귀 - 데이터의 경향을 곡선으로 표현

🚘 사용 방법

  1. 자동차 무게를 입력합니다.
  2. 예측 모델을 선택합니다.
  3. 연비 예측 버튼을 누릅니다.
  4. 결과와 그래프를 확인합니다.

🚘 자동차 정보 입력

자동차의 무게를 파운드(lb) 단위로 입력해주세요.

자동차 데이터를 불러오는 중...

📈 연비 예측 그래프

자동차 무게와 실제 연비 데이터의 관계를 회귀선과 함께 보여줍니다.

📊 모델 성능 비교

두 회귀 모델의 예측 오차(MSE)와 설명력(R²)을 비교합니다.

모델 평가 결과를 계산하는 중...
※ MPG는 미국식 연비 단위이며 km/L로 변환하여 함께 표시합니다.
※ 실제 연비는 운전 습관과 도로 상태 등에 따라 달라질 수 있습니다.
```
