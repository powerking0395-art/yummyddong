자동차 연비 예측 계산기

자동차의 무게 데이터를 기반으로 회귀 모델을 학습하여 예상 연비를 계산합니다. 선형회귀와 비선형회귀 모델을 비교하고 데이터의 관계를 그래프로 확인할 수 있습니다.

📌 계산기 사용 안내

자동차 무게와 연비 데이터를 이용하여 머신러닝 모델을 학습합니다.

📈 예측 모델

  • 선형회귀 - 데이터의 경향을 직선으로 표현
  • 비선형회귀 - 데이터의 경향을 곡선으로 표현

🚘 사용 방법

  1. 자동차 무게를 입력합니다.
  2. 예측 모델을 선택합니다.
  3. 연비 예측하기를 클릭합니다.
  4. 예측 결과와 그래프를 확인합니다.

🚘 자동차 정보 입력

자동차의 무게를 입력하고 예측 모델을 선택해주세요.
