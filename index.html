자동차 연비 예측 계산기

자동차 무게를 입력하면 기존 자동차 데이터를 학습한 회귀 모델을 이용하여 예상 연비를 계산합니다.

예측 방법

  • 선형회귀: 데이터의 경향을 직선으로 표현하여 예측합니다.
  • 비선형회귀: 데이터의 경향을 곡선으로 표현하여 예측합니다.

사용 방법

  1. 자동차 무게를 파운드 단위로 입력합니다.
  2. 예측 모델을 선택합니다.
  3. 연비 예측하기 버튼을 누릅니다.
  4. 예상 연비와 그래프를 확인합니다.
